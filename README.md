# 2026_Project — 돼지 사료통 점유(visiting) 마리 수 추정

돈방 CCTV 영상에서 **시간대별로 사료통을 차지한(visiting) 돼지 수**를 자동으로 세는 연구 코드.
2026 MIX_Lab 학부연구생 「육돈 사료통 점유 시간 계측 연구」 과제용.

- 학습: 001(CH005) + 002(CH010) 190장
- test: 000(1분 샘플 영상) 86장 — 학습에 쓰지 않은 다른 카메라
- 비교: 돼지마다 visiting 판정하는 방법 5가지 — **Geo / RF / RF+Geo / RF+Geo+Leg / YOLO**

진행 내용과 결과는 [PROGRESS.md](PROGRESS.md)에 단계별로 자세히 기록.

### 포즈 추정 결과 요약 (test = 000)

| 사이즈 | epoch 100 → 200 → 300: pose mAP50-95 | PCK@0.1 | PCK@0.2 | 학습 시간(분) |
|---|---|---|---|---|
| nano | 0.079 → 0.101 → 0.059 | 0.667 → 0.685 → 0.628 | 0.861 → 0.867 → 0.857 | 3.3 → 6.2 → 8.8 |
| small | 0.060 → 0.103 → 0.084 | 0.701 → 0.689 → 0.655 | 0.850 → 0.856 → **0.871** | 4.6 → 8.6 → 12.7 |
| **medium** | 0.091 → 0.100 → **0.132** | 0.684 → **0.710** → **0.710** | 0.865 → 0.870 → 0.857 | 7.9 → 15.3 → 22.7 |
| large | 0.059 → 0.107 → 0.110 | 0.673 → 0.668 → 0.687 | 0.866 → 0.834 → 0.869 | 16.1 → 31.5 → 45.0 |

- 100 → 200: 모든 사이즈에서 mAP 오름. PCK(관절 점이 정답 근처에 들어온 비율)는 차이 작음.
- 200 → 300: valid(학습과 같은 카메라)는 계속 오르지만 000(처음 보는 카메라)에서는 사이즈마다 엇갈림 → 학습 카메라에 더 맞춰지는 효과.
- medium ep300으로 visiting 판정까지 돌려 봐도 ep200과 같거나 조금 나쁨(RF+Geo MAE 0.093 → 0.105) → **medium ep200** 계속 사용.

### visiting 판정 결과 요약 (사진당 visiting 마릿수 기준)

최종 test = 000(1분 샘플 영상 86장, 포즈 모델 관절). 사진당 visiting 0\~2마리, 평균 1.55.

| 방법 | 사진당 MAE (bias) | 정확 일치 | 1분 총 점유량 오차 | 10초 구간 평균 오차 | 참고: 001+002 사람 관절 MAE |
|---|---|---|---|---|---|
| Geo (방향 60°) | 0.279 (−0.279) | 73.3% | −18.0% | 0.234 | 0.589 |
| Geo (방향 90°) | 0.093 (−0.047) | 90.7% | −3.0% | 0.069 | 0.589 |
| RF | 0.105 (−0.012) | 89.5% | −0.8% | 0.062 | 0.647 |
| **RF+Geo** | **0.093 (0.000)** | **90.7%** | **0.0%** | 0.069 | 0.205 |
| **RF+Geo+Leg** | **0.093 (0.000)** | **90.7%** | **0.0%** | 0.069 | **0.079** |
| YOLO (수아) | — | — | — | — | — |

- 000에서 RF+Geo(+Leg)가 가장 좋음: 86장 중 78장 마릿수 정확, 모든 사진 ±1마리 이내.
- Geo(60°)는 점유량을 18% 적게 셈. 90°는 000에서는 좋지만 001+002에서는 16.5% 많이 셈 → 카메라마다 다시 맞춰야 함.
- 000에서 남은 오차는 대부분 포즈 모델이 돼지를 못 찾거나 더 찾은 경우 → 판정보다 검출 쪽 개선이 다음 과제.

## 데이터

| task | 카메라 | 사진 | 돼지 (visiting / other) | 용도 |
|---|---|---|---|---|
| 001 | CH005 (1920×1080) | 90 | 899 (136 / 763) | **학습** — 포즈 모델, RF 계열 |
| 002 | CH010 (1920×1080) | 100 | 990 (179 / 811) | **학습** — 포즈 모델, RF 계열 |
| 000 | 1분 샘플 영상 (960×720) | 86 | 860 (133 / 727) | **test** — 학습에 전혀 안 씀 |

- 모든 사진에 사람이 CVAT로 스켈레톤(관절 18개)과 State(visiting / other)를 라벨링.
- 포즈 모델 분할: 001+002를 train 162 / valid 28로 나누고, 000 86장은 통째로 test.
- test(000)는 학습(CH005·CH010)과 **다른 카메라·해상도** → 처음 보는 화면에서의 성능을 잼.

## 비교하는 판정 방법 (②)

| 방법 | 어떻게 판정 | 학습 | 담당 |
|---|---|---|---|
| **Geo (규칙 기반)** | 코·목 신뢰도 ≥ 0.5, 코가 사료통 원 안, 목→코 방향이 사료통 중심에서 60° 이내 → visiting | 없음 | |
| **RF** | 자세 특징 6개 → RandomForest | 001+002 | |
| **RF+Geo** | RF 특징 + Geo 값 5개(코-사료통 거리 ÷ r, 머리 방향 각도 등) | 001+002 | |
| **RF+Geo+Leg** | RF+Geo + 다리 모양 누움 특징 5개(다리-척추 각도, 다리 길이, 발 쏠림 등) | 001+002 | |
| **YOLO** | 포즈 없이 YOLO가 돼지를 visiting / other로 바로 검출 | 001+002 | 수아 |

- 특징 정의: `counting/src/feeding_monitor/` (`feeding_classifier.py`, `posture_features.py`, `leg_features.py`, `method_features.py`).
- 사료통 원(cx, cy, r)은 카메라마다 따로 잡음(`counting/configs/eval_cameras.yaml` — CH005, CH010, SAMPLE).
  특징은 r·몸통 길이로 나눈 비율이나 각도라 카메라 높이·사료통 크기 차이에 영향을 덜 받음.

### 평가

| | Stage 1 | Stage 2 (최종 test) |
|---|---|---|
| 데이터 | 001+002 | 000 |
| 관절 | 사람이 찍은 관절 | **포즈 모델이 찍은 관절** (실제 운용과 같음) |
| 학습/시험 | 클립 단위 교차검증 (같은 클립 사진이 학습·시험에 나뉘지 않게) | 001+002 전체로 학습 → 000에 적용 |
| 지표 | 사진당 visiting 마릿수 오차 | 사진당 visiting 마릿수 오차 + 구간(약 10초) 집계 오차 |

- **정답은 000(1분 샘플 영상)의 사람 라벨만 사용.**
- 지표: 사진당 마릿수 MAE, bias(많이/적게 세는 쪽), 정확 일치율, ±1 이내 비율, 총 점유량 오차(%), 구간 집계 오차.
  MAE와 bias를 같이 봄(많이 센 사진과 적게 센 사진이 bias·총 점유량에서 상쇄되기 때문).
